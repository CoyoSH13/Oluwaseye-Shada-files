# Network Infrastructure Photos

Organised collection of network and infrastructure photographs for the Oluwaseye-Shada-files private repository.

Contents include Cisco and Fortinet network equipment, ADVA/Alcatel infrastructure, fibre and patch-panel installations, Cisco C9115AXI access point hardware, wireless AP installations, and Cisco equipment boxes.

Note: Some photographs contain equipment labels, serial numbers, MAC addresses, asset identifiers, and site/network labels. Keep this repository private and review/redact sensitive details before sharing any image publicly.
